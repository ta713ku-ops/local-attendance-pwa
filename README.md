# ローカル勤怠・給与見込み管理（iPhone PWA）

店舗の共用iPhone 1台で使う、完全ローカル運用の勤怠・給与見込みPWAです。初回導入とアプリ更新時だけHTTPS配信へ接続し、従業員・勤怠・給与データはiPhone内のIndexedDBへ保存します。外部サーバーへ勤怠データを送信しません。

> 表示金額は、基本賃金と深夜25%割増だけを含む参考値です。残業・休日割増、税、保険、控除は含みません。30分丸めの本番運用は、労務専門家の確認後に開始してください。

## 開発

```bash
npm install
npm start
```

`npm start` はiPhone確認用のWeb開発サーバーを起動します。PWAとしてのホーム画面追加とオフライン動作にはHTTPSが必要です。

品質確認:

```bash
npm run typecheck
npm test
npm run build:pwa
npm run preview:pwa
```

旧Electron版のソースは移行時の参照用として残していますが、現在の実行・納品対象はiPhone PWAだけです。

## 初回運用

1. iPhoneのSafariで納品されたHTTPS URLを開きます。
2. 共有メニューから「ホーム画面に追加」を選びます。
3. ホーム画面の「ローカル勤怠」を開き、6桁の管理者PINを設定します。
4. 一度だけ表示される回復コードを別の安全な場所へ保存します。
5. 管理画面から従業員と時給を登録します。

詳しい導入・更新手順は [iPhone版の導入と運用](docs/PWA_DELIVERY.md) を参照してください。

## データとバックアップ

- 勤怠データ、管理者PINのハッシュ、設定、操作ログはiPhone内へ保存します。
- PINと回復コードの平文は永続化しません。
- iPhoneの故障・初期化・紛失、SafariのWebサイトデータ削除に備え、管理画面から定期的にJSONバックアップを書き出してください。
- バックアップファイルはこのiPhoneの外にも保管してください。
- 同じHTTPSのoriginを維持しないと、iPhone上では別アプリ・別データとして扱われます。

## 対応範囲

打刻、従業員・時給管理、勤怠履歴、訂正・承認、月次集計、CSV、印刷、操作ログ、バックアップ・復元、管理者PINを対象にします。

休憩、シフト作成、有給、残業・休日計算、税・保険、給与明細、複数店舗、複数端末同期、クラウド保存は対象外です。将来はシフト情報と連動し、当日の出勤予定者を打刻ホーム上部へ優先表示する予定です。
