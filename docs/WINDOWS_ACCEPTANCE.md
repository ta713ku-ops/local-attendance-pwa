# Windows 11 導入・受入チェックリスト

## 導入前に必須

- [ ] 30分単位の日次丸め運用について、社労士等の労務専門家から確認を得た
- [ ] 対象PCのWindowsエディション、バージョン、x64、画面解像度を記録した
- [ ] 専用Windowsアカウント、強固なサインイン、BitLocker、OS自動更新を設定した
- [ ] 管理者PINと回復コードを安全な別媒体へ保管した
- [ ] インストーラーの発行元またはSHA-256を記録した

## 実機受入

- [ ] 1366x768以上で全画面起動し、二重起動が既存画面へ集約される
- [ ] 初回PIN設定、失敗ロック、再認証、ロック後の入力復帰を確認した
- [ ] 出勤、退勤、同日再出勤、16時間超過、短時間例外を確認した
- [ ] 月末・年末・深夜帯のテストデータで期待値と一致した
- [ ] CSVを対象PCのExcelで開き、日本語・時刻・金額・BOMを確認した
- [ ] A4横でページ番号、年月、従業員名、注意文が印刷される
- [ ] 手動バックアップ、破損バックアップ拒否、復元前退避、復元成功を確認した
- [ ] アプリ強制終了後に復旧案内が表示され、現在DBが保護される
- [ ] ディスク容量不足とバックアップ先アクセス不可で、打刻保存結果が明示される
- [ ] アップグレード前バックアップと、旧データを保持した上書き導入を確認した
- [ ] アンインストール後も利用者データが意図どおり保持される

## 未対応なら受入不可

労務確認、対象店舗PC、実プリンター、Windows 11 x64インストーラー、コード署名の各確認はmacOS上の開発だけでは完了できない。結果、担当者、確認日をこの文書または店舗の運用台帳へ追記する。
