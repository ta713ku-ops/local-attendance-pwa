# iPhone PWA管理者画面 実装基準

この文書は、2026年8月1日に確定した「iPhone PWA管理者画面シンプル化・安全化計画」を実装・レビュー・受入の基準として固定する。詳細要件は同計画書に従い、矛盾する旧画面仕様より本書を優先する。

## 対象と非対象

- 対象はiPhone PWA版だけとし、管理者画面を「勤怠・従業員・月次・設定」の4タブへ整理する。
- 旧Electron版、休憩・残業・休日・税控除、クラウド同期は対象外とする。
- 勤怠・給与・訂正・操作履歴は自動削除しない。完全削除はPWA画面から除き、APIも方針未確定エラーを返す。
- 5年保存方針と完全削除の扱いは別途決定し、本機能を法令適合済みとは表示しない。

## デザイン契約

- visual intent: 清潔で高コントラストなEnterprise UIにより、iPhone上の日常管理を迷いなく完了できる画面にする。
- 色は既存の `primary #072c2c`、`success #15803d`、`warning #b45309`、`danger #b91c1c`、白いカード、暖色系グレー背景を使う。
- 下部タブは文字だけとし、選択中をsuccess色の文字、上線、`aria-current="page"`で示す。
- 本文は日本語システムフォント、16pxを基準とし、8pxの余白単位、4px/8pxの角丸、境界線中心の階層を維持する。
- すべての操作領域は44px以上。`focus-visible`、disabled、loading、error、emptyを実装する。
- ダイアログはフォーカストラップ、Escape、背景スクロール停止、閉じた後のフォーカス復帰を備える。
- 390x844、430x932、横向き、200%文字拡大で横方向の欠落を起こさない。
- グラデーション、ガラス表現、装飾アイコン、曖昧な危険操作、ブラウザー標準confirmを管理フローへ使わない。

## データと計算の契約

- 元打刻と元時給スナップショットは不変とし、最新の適用済み訂正から実効値を求める。
- 実効出勤日を勤務日・所属月とし、出勤30分切り上げ、退勤30分切り下げ、深夜22:00から翌5:00を適用する。
- 金額は1/240円単位で保持し、従業員月合計を1円に四捨五入する。配分差額は端数、勤務日、出勤時刻、勤務ID、通常分優先の安定順で割り当てる。
- 勤務中・要確認・旧承認待ちは出勤回数へ含めるが、確定するまで時間と金額へ含めず、除外件数を表示する。
- 管理者訂正は `APPROVED` として即時保存し、全履歴を残す。旧 `PENDING` は即時反映または取り消しで解決する。
- 訂正による移動元または移動先の月が確定済みなら保存を拒否する。
- 月次、日別、Excel用データ、印刷は同じ配分済み集計結果を利用する。

## バックアップ契約

- IndexedDBは既存ストアを維持し、既存v1レコードを既定値付きで読む。バックアップ形式をv2へ上げ、v1/v2を復元できるようにする。
- アプリ内バックアップは `AUTO / MANUAL / PRE_RESTORE` に限定し、JST日付で同日のAUTOを重複作成しない。
- 起動時と前面復帰時に、未認証でも当日分AUTOを内部作成する。90日を超えたアプリ内バックアップだけを削除する。
- 復元前に形式と必須項目をメモリ上で検証し、PRE_RESTOREを作成する。管理者認証を除く対象を単一トランザクションで置換・読み戻しし、失敗時は中止する。
- 現在の管理者PIN・回復コードは復元で変更しない。成功後はセッションを破棄して再認証を要求する。
- アプリ内バックアップは同一端末・同一オリジンにあり、端末故障やストレージ消去への完全な保護ではないと表示する。

## APIと画面の契約

- Electron共通APIを増やさず、PWA専用 `PwaAttendanceApi` と型付きDTOを使用する。画面は生レコードを再集計しない。
- 勤怠は月カレンダー、日一覧、勤務詳細、日合計を表示する。
- 従業員は追加・編集・将来時給変更・削除・30日復元を提供し、在籍と削除済みを分けて五十音順にする。
- 月次は従業員別一覧、別画面の日別詳細、阻害件数を含む月合計、確定・取り消し、Excel用データ保存、印刷を提供する。
- 設定トップには「管理者PINの変更・バックアップ・出勤訂正」だけを置く。
- 金額付近と出力物へ「※残業・休日割増は含まれていません」を表示する。

## 最終ゲート

- `npm run typecheck`
- `npm test`（`tests/domain`、`tests/shared`、`tests/pwa`）
- `npm run build:pwa`
- 再起動したPWAでiPhone寸法、長い氏名、0件、勤務中、要確認、削除済み、訂正済み、確定済み、キーボード、フォーカス、印刷を確認する。
- iPhone実機で保存・復元・印刷を確認するまでは、本番運用受入済みとは扱わない。
