# iPhone版（PWA）の導入と運用

## 初回導入

1. 管理者から案内された **HTTPS のURL** を、対象iPhoneのSafariで開きます。
2. 共有ボタンから「ホーム画面に追加」を選び、「追加」します。
3. 以後はホーム画面の「ローカル勤怠」アイコンから開いてください。初回に必要な画面を読み込めていれば、通常の打刻はオフラインでも利用できます。

Safari以外のブラウザや、URLを直接開いたままの利用では、ホーム画面アプリとしての動作・オフライン利用を確認できません。

## 保存場所と注意

勤怠データはこのiPhoneのブラウザ保存領域に保存されます。外部サーバーへ自動送信しません。ただし、iPhoneの初期化、SafariのWebサイトデータ削除、端末の故障・紛失で失う可能性があります。

管理者はアプリのバックアップ機能で定期的にバックアップを作成し、**別の安全な保管先**へ移してください。復元は、同じアプリ・同じ保存形式を使う端末で行います。

## 更新方法

更新版を配信するときは、必ず初回導入時と **同じHTTPSのorigin（ドメイン、プロトコル、ポート）** で公開してください。originが変わると、iPhoneは別アプリ・別の保存領域として扱います。

1. iPhoneをネット接続し、ホーム画面のアプリを開きます。
2. 更新のお知らせが表示された場合、打刻中の操作がないことを確認してから更新します。
3. 更新後に一度アプリを閉じ、ホーム画面から開き直します。

更新前にもバックアップを作成してください。オフライン中は既に保存済みの版を使い続け、ネット接続後の次回起動時に更新を取得します。
